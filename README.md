# GitHub Repo Viewer

GitHub の公開リポジトリをカード表示し、名前検索・言語フィルタ・更新日／スター数／名前順の並び替えを行うブラウザアプリです。Vite + TypeScript、実行時の外部ライブラリなし。

## 起動と検証

Node.js 22.12 以降（Node.js 24 推奨）を使用します。PowerShell では以下を実行してください。

```powershell
npm install
npm run dev
npm run build
npm test
```

開発サーバーが表示する localhost の URL を開きます。ビルド出力は `dist/`。`npm run preview` でビルド結果を確認できます。

テストは Vitest + happy-dom で DOM 操作とモック通信を検証します。実ブラウザも実際の GitHub API も呼びません。

## 使い方

1. GitHub ユーザー名を入力し、「リポジトリを取得」を押します。公開リポジトリを表示します。
2. 名前検索と言語フィルタは組み合わせられます。並び替えは更新日降順・スター数降順・名前昇順です。
3. 同じユーザー名で10分未満の再取得は保存結果を利用します。「キャッシュを破棄」は通信せず、次の取得時に再通信します。

最大100件×3ページまで取得します。300件を超える場合は画面に通知し、取得した範囲だけを検索・並び替えします。API 残回数は最終レスポンスの値で、キャッシュ利用時は取得時点の値です。レート制限を超過するとリセット時刻を表示します。

取得結果はこのブラウザの localStorage に最新の1件分を保存します。ユーザー名の初期値は空欄です。保存できない場合も画面内で閲覧を続けられます。

現行仕様は `docs/specs/v2-remove-token.md` を優先し、変更のない項目は v1 の `docs/specs/mvp.md` に従います。設計判断は `docs/decisions/`、処理の流れは `docs/walkthrough.md`、ファイルの役割と公開関数は `docs/modules.md` にあります。
