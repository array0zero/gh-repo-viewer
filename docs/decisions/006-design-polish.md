# CSS で既存のダークデザインを整理する

- 状態: 採用（Issue #3）
- 決定: 既存の配色とDOM構造を維持し、CSSで余白・文字・境界・カード内の配置とレスポンシブ表示を整える。
- 理由: 見た目の改善が目的であり、通信や状態管理の変更を必要としない。既存の操作と表示項目を維持したまま改善でき、依存や外部アセットも不要なため。
- 影響: 操作要素の最小高さ44px、折り返し、フォーカス表示を揃える。カードを縦方向のflex配置にしてメタデータを下端に置く。フッターの11px指定は維持する。
- 仕様: [Issue #3 のデザイン仕様](../specs/v3-design.md)。
