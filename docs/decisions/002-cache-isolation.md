# 取得条件ごとに識別した10分間のキャッシュ

- 状態: 採用
- 決定: localStorage に最新の成功結果を1件保存し、保存時刻から10分未満のみ再利用する。ユーザー名とトークンの SHA-256 を照合する。
- 理由: 公開・非公開や別のトークンの結果を混用せず、トークン文字列をキャッシュに重複保存しないため。
- 影響: トークン自体は仕様に従い localStorage に保存する。キャッシュにも非公開リポジトリのメタデータが含まれ得る。トークン欄を空にすると保存トークンを削除し、キャッシュ破棄ボタンで取得データを削除できる。
- 障害時: 不正・期限切れのキャッシュは無視する。保存失敗は画面通知する。全ページ成功時だけ保存し、部分データで既存のキャッシュを上書きしない。
