- 状態: 表示文字列は [007-footer-version.md](007-footer-version.md) により更新（Issue #5）。既存スタイルの利用は継続。
- 決定: リポジトリ一覧の後にある既存の footer 要素を再利用し、表示文字列を `gh-repo-viewer` のみにする。既存の 11px・中央揃えのスタイルを利用する。
