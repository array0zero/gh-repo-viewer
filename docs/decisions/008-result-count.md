# 一覧描画と同時に件数を更新する

- 状態: 採用
- 決定: 既存の count 要素をカード一覧の直前へ移動し、render 内で表示対象配列と取得結果配列の長さを使って `N 件 / 全 M 件` を表示する。既存の loaded が false の間は hidden にして文字列も空にする。
- 理由: カードと同じデータから計算することで検索・言語フィルタ・並び替え・キャッシュ表示で件数がずれず、追加の状態管理や通信が不要なため。取得成功した0件と未取得も区別できる。
- 影響: 件数の書式・位置・表示条件のみを変更し、元の文字スタイルと API 残回数の右寄せを維持する。件数の更新は aria-live で通知する。
- 仕様: [絞り込み結果の件数表示](../specs/v4-result-count.md)。
