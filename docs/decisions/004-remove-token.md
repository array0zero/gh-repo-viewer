# 公開リポジトリ専用にしてトークン機能を除去する

- 状態: 採用（v2）
- 決定: トークン入力・保存・読み出し、Authorization ヘッダー、認証 API と affiliation 指定、401 専用処理を削除する。入力されたユーザー名の `/users/{username}/repos?type=owner` のみを利用する。
- 理由: 第三者向けの公開ツールで、初見の訪問者に PAT を預けてもらう設計は適切でないため。代替の認証は追加しない。
- キャッシュへの影響: 識別子は前後の空白を除き小文字にしたユーザー名のみとし、SHA-256 は不要になる。保存キーを `gh-repo-viewer:cache:v2` に変更して旧形式を再利用しない。最新の成功結果1件・10分未満・手動破棄の仕様は維持する。旧保存領域の読み出しや移行は行わない。
- UI への影響: 入力欄と案内を削除し、フォームを残った2要素の列数に合わせる。ユーザー名は空欄で起動する。空欄送信はアプリのメッセージで案内するため required による送信阻止を外し、既存のユーザー名パターン検証は維持する。
- 維持するもの: カード項目、検索、言語フィルタ、並び替え、最大3ページ、レート制限と404・通信障害・0件の扱い。
- 仕様: [v2](../specs/v2-remove-token.md) を優先し、変更のない部分は [v1](../specs/mvp.md) に従う。
