# 絞り込み結果の件数表示

## 仕様

- カード一覧のすぐ上に `N 件 / 全 M 件` を表示する。既存の件数表示を置き換える。
- N は名前検索と言語フィルタを適用した後のカード数、M は取得したリポジトリ数とする。
- 検索文字・言語の変更時に即座に更新する。並び替えで件数は変わらない。
- 未取得時は表示しない。取得中や失敗時など一覧をクリアした状態でも表示しない。
- API 取得・キャッシュ利用のいずれも同じ表示にする。取得結果が空なら `0 件 / 全 0 件`、絞り込み結果が空なら `0 件 / 全 M 件` とする。
- API 取得方法、キャッシュ、300件上限の通知、件数以外の見た目は変更しない。M は GitHub 上の総数ではなく実際に取得した数とする。

## 受入条件

1. 取得成功後、カード一覧の直前に指定書式の件数が表示される。
2. 名前検索と言語フィルタを単独・併用・解除した時、N が表示カード数と一致し、M は維持される。
3. 全ての並び替えで N と M が変化しない。
4. 未取得時は検索操作をしても件数が表示されない。
5. キャッシュ表示でも同じ件数表示・更新が行われ、追加通信しない。
6. 取得結果0件・検索結果0件の件数も表示される。
7. 件数表示と更新のテストを追加し、`npm run build` と `npm test` が成功する。
