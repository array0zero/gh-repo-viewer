## div goal が複数の仕様ファイルを単純連結する

`docs/specs/` に複数ファイルがある場合、`div goal` は全ファイルの完了条件を
そのまま連結して出力する。v1 と v2 で矛盾する条件（トークン欄の有無など）が
並ぶため、そのままエージェントに渡すと破綻する。

新旧の優先順位を表現する仕組みが必要。ファイル名の規約か、front matter か、
または `div goal <project> <spec>` のように対象を指定できるようにするか。
div-cli 側の課題として別途対応する。
